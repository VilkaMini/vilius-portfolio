The Raid of Brunswick

An interactive game about a raid of brunswick during World War 2 where you play through 5 crew stations and experience what it was like to be part of a bomber crew.

A IWP (Y4 Semester 1) project focusing in showing hidden heritage of Groningen area.

About the Development

As the Lead Programmer I implemented modular minigame system that allowed fast iteration and creation of minigames as well as majority of the minigames functionality.

Minigame Component Parent

The minigame system utilized inheritance to create a modular system that could be used to create minigame components such as interactables and query commands to them to facilitate the gameplay functionality.

This system handled timeouts, command queue and input processing within the components to manage them from the director blueprint.

Minigame Implementation

Using the minigame components I was able to quickly implement each minigame with it's own twist and different control schemes, such as using interaction between objects as well as handling of timed events.

The pilot minigame required rotation checks in the code for pilot wheel and lever to check whether the player completed their tasks.
